# OnChain interactive prototype

Open `index.html` in a browser. This self-contained prototype needs no server, Redis, provider credentials, or internet connection.

The Home, empty search, loading, overview, eight profiler tabs, transaction detail, protocol filtering, invalid-address state, and smart-contract state are clickable. The six sample addresses are synthetic and switch between the six supported behavioral profiles. Every figure is illustrative; this file does not perform on-chain analysis.

To review at desktop size, use a browser window about 1440 pixels wide. The layout also adapts to mobile widths. The prototype is kept separate from the production frontend and backend.

If a Figma connection becomes available, these screens and flows can be recreated in an editable Figma file. The `index.html` file is already a usable click-through presentation artifact.
